## Task 2 in brief

* **Model:** Autoformer (series decomposition + Auto-Correlation; layers adapted from [thuml/Autoformer](https://github.com/thuml/Autoformer), MIT licence), ~22k parameters, plus a 15-parameter linear head on covariates known over the forecast horizon.
* **Validation:** chronological split; 24 non-overlapping 168-step evaluation blocks; 3 seeds per configuration.
* **Covariate ablation** (mean RMSE over 24 blocks, 3 seeds):

| Variant | RMSE |
|---|---|
| No covariates | ≈ 83.4 |
| Covariates in encoder only | ≈ 84.1 |
| **Covariates in encoder + decoder (known over the horizon)** | **≈ 60.5** |
| Flat training-mean baseline | 82.9 |

Covariates help only when they cover the forecast horizon. Covariates known only up to the forecast origin add nothing.
